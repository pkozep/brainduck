# BrainDuck

**BrainDuck** — язык программирования, созданный для упрощения написания программ на эзотерическом языке Brainfuck. Он сохраняет низкоуровневую природу Brainfuck, но добавляет удобные конструкции для работы с переменными, массивами и управляющими операторами.

## Синтаксис

### 1.0 Переменные


В BrainDuck реализованы два типа памяти:
- **статическая** (объявляется до динамической);
- **динамическая**.

#### 1.1 Объявление переменных (статическая память)

Формат:  
```
det[<размер_в_байтах>] <имя_переменной>;
det[<размер_в_байтах>] <имя_переменной> = <значение>;
```

Примеры:
```brainduck
det[1] a;
det[1] b = 3;
det[1] c = b;
```
#### 1.2 Использование переменных (статическая память)
После объявления переменная доступна по имени:

```brainduck
a = 4;
a = b;
a = 3 + c;
```
#### 1.3 Указатели и разыменование
Оператор & возвращает индекс переменной.

Оператор * позволяет разыменовать индекс (скопировать значение или изменить его).

Пример:

```brainduck
a = &b;     # a хранит индекс переменной b
*a = 2;    # эквивалентно: b = 2
```
### 2.0 Массивы
#### 2.1 Статическое выделение массивов
Массив — статически выделенная переменная размером больше одного байта. Доступ к элементам через индекс в квадратных скобках.

Пример:

```brainduck
det[3] a;      # массив из 3 элементов
a[0] = 1;
a[1] = 2;
a[2] = 3;

det[1] n = 1;
a[n] = 10;     # использование переменной как индекса
```
#### 2.2 Динамическое выделение массивов
Для динамического выделения используется оператор new:

```brainduck
det[1] n = 1;
det[1] a = new(3);  # выделяет 3 элемента, возвращает индекс первого
*a[0] = 2;
*a[n] = 3;
```
### 3.0 Управляющие конструкции
#### 3.1 Условный оператор (if)
Блок выполняется один раз, если условие не равно нулю:

```brainduck
if <выражение> {
    <команда 1>;
    ...
    <команда N>;
};
```
#### 3.2 Цикл while
Блок выполняется, пока условие не равно нулю:

```brainduck
while <выражение> {
    <команда 1>;
    ...
    <команда N>;
};
```
## Примеры кода
##### Пример 1: Простая арифметика

```brainduck
det[1] a = 5;
det[1] b = 3;
a = a + b;  # a = 8
```
##### Пример 2: Использование указателей

```brainduck
det[1] x = 10;
det[1] ptr = &x;
*ptr = 20;  # x = 20
```
##### Пример 3: Цикл с массивом

```brainduck
det[1] i = 0;
det[5] arr;
while i != 5 {
    arr[i] = i * 2;  # заполнение массива чётными числами
    i = i + 1;
};
```
